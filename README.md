# Zenstudy ライブ授業教材制作

Zenstudy の教材制作と、その依頼・方針・会話・成果物・変更履歴を保存するプロジェクトです。

GitHub の保存先: [koushinjyuku-material/zen_live](https://github.com/koushinjyuku-material/zen_live)

## 続きから作業する

このプロジェクトを開いて、作りたい教材や変更点を伝えてください。継続指示は [AGENTS.md](AGENTS.md)、確定した条件は [制作方針](docs/制作方針.md)、現在地は [進行状況](docs/進行状況.md) に保存します。

Codex がプロジェクトの `AGENTS.md` を作業開始時に読み込む仕組みを使います。別の作業場所で続ける場合も、このリポジトリーを開いて作業します。[OpenAI 公式ドキュメント](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

## 保存場所

| 場所 | 保存する内容 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | 次回以降も適用する作業・記録・GitHub 同期の指示 |
| [docs/制作方針.md](docs/制作方針.md) | 利用者が指定した目的、条件、好み、保存先 |
| [docs/進行状況.md](docs/進行状況.md) | 現在の作業、未確定事項、次に行うこと |
| [records/](records/) | 日付ごとの依頼・回答、決定、作業結果 |
| [materials/](materials/) | 授業ごとの教材の編集元、配布物、図版、参照情報 |
| Git のコミット履歴 | 保存したファイルの変更履歴 |

## 記録と同期の運用

作業のたびに日次記録と必要な引き継ぎ情報を更新し、成果物と一緒にコミットして GitHub に反映します。記録には、確認できた利用者の依頼と最終回答の原文、実施内容、判断理由、確認結果、残っている作業を含めます。

初期設定時、端末の Git アカウントには対象リポジトリーへの書き込み権限がなかったため、アプリの GitHub 連携を保存経路にしています。次回もこの方法を参照できるよう `AGENTS.md` に記録しています。

これは、このプロジェクトで作業する際にエージェントが実行する運用です。アプリの全会話データをバックグラウンドで自動エクスポートする機能は設定していません。過去の会話を取り込む際は、実際に取得できた内容だけを保存します。

GitHub への反映が失敗した場合は、ローカルに記録を残し、未反映として報告します。接続回復後に同期を再開します。

「Zenstudy」の保存先はこの教材制作プロジェクトです。ZEN Study のサービス内への投稿・登録は行いません。GitHub の公開範囲は初期設定時点で public です。
