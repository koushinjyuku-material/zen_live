アシスタント:

>
> 毎回引き継ぐ指示、会話・作業記録、教材の保存場所を用意し、今回の依頼も最初の記録として保存します。

アシスタント:

> 継続指示と今回の記録をファイルに保存しました。次回からは、このプロジェクトで作業する際に方針を読み、記録の更新と GitHub への同期まで進める運用にしています。
>
> 現在、GitHub の接続先を登録するため、実行環境が保護している `.git/config` の変更許可を待っています。

アシスタント:

> Git の送信で、端末にログインしているアカウントに書き込み権限がないことが分かりました。アプリの GitHub 連携にはこのリポジトリーへの書き込み権限があるため、そちらから保存を進めます。この接続方法も次回用の指示に残します。

## 決定と理由

- このプロジェクトを Zenstudy の教材制作専用とする。
- 次回の作業開始時に同じ方針を参照できるよう、リポジトリー直下に `AGENTS.md` を置く。
- 方針、現在地、日次記録、教材をファイルで保存し、GitHub にも反映する。
- 保存先の確認により、ZEN Study のサービス内への投稿・登録は対象に含めない。

## 実施内容・確認結果

- ローカルはコミットとリモート設定がまだない Git リポジトリーだった。
- GitHub 連携で `koushinjyuku-material/zen_live` を特定。空のリポジトリーで、既定ブランチは `main`、公開範囲は public。
- GitHub へのネットワーク接続は実行環境の制限により最初は失敗。制限外での接続確認が許可され、リモートに参照がないことと GitHub CLI のログインを確認した。
- `AGENTS.md`、`README.md`、`docs/制作方針.md`、`docs/進行状況.md`、本記録、`materials/README.md`、`.gitignore` を作成した。
- 継続指示の読み込み仕様を [OpenAI 公式ドキュメント](https://learn.chatgpt.com/docs/agent-configuration/agents-md) で確認した。
