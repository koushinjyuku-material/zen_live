## 判定

4題とも物理的に成立し、与条件から解が一意に定まる。熱力学第一法則を `Q = ΔU + W`（`W` は気体が外部にした仕事）とすれば、下記の符号と数値になる。基本事項から三角形サイクル・断熱圧縮までの演習として妥当。

全題の対象を一定量の単原子分子理想気体とし、`U = (3/2)nRT` を共通条件として明記すると曖昧さがない。容器やピストン自身の熱容量を無視する理想化も共通または第2問に記載するとよい。

## 第1問: 三角形サイクル

状態は `A(V0,p0)`, `B(2V0,2p0)`, `C(2V0,p0)`。`E = p0V0 = nRT0` と置く。

- 状態方程式より `TA = T0`, `TB = 4T0`, `TC = 2T0`。
- `A → B` の仕事は台形の面積: `WAB = (p0+2p0)(2V0−V0)/2 = 3E/2`。
- `B → C` は定積なので `WBC = 0`。
- `C → A` は定圧圧縮なので `WCA = p0(V0−2V0) = −E`。

| 過程 | 気体がした仕事 W | 内部エネルギー変化 ΔU | 吸収熱量 Q |
| --- | ---: | ---: | ---: |
| A → B | 3E/2 | 9E/2 | 6E |
| B → C | 0 | −3E | −3E |
| C → A | −E | −3E/2 | −5E/2 |
| 1周の合計 | E/2 | 0 | E/2 |

`A → B → C → A` は時計回りであり、正味の仕事は三角形の面積 `E/2` と一致する。`A → B` では温度が単調に上昇して膨張し、途中も吸熱する。残り2過程はともに放熱するため、吸収熱量の総和は `Qin = 6E`。したがって `η = (E/2)/(6E) = 1/12 ≒ 8.3%`。

熱効率の分母は「1周で吸収した熱量の合計」であり、正負を含む熱量の合計 `E/2` ではない。この区別を問題または解説で明確にする。

## 第2問: 定圧・定積・断熱操作を行うピストン

外側が真空の水平円筒で、摩擦を無視できる質量の無視できるピストンを外力 `F` で準静的に動かす設定は成立する。動く際の力のつり合いは `F = pS`。必要時に熱窓から熱を出入りさせ、閉じた場合は断熱とする。

`E = p0V0 = nRT0` と置く。

| 状態 | 圧力 | 体積 | 温度 |
| --- | --- | --- | --- |
| A | p0 | V0 | T0 |
| B | p0 | 2V0 | 2T0 |
| C | p0/2 | 2V0 | T0 |
| D | 2^(2/3)p0 | V0 | 2^(2/3)T0 |

### 操作 I: A → B（定圧膨張）

- `WI = p0(2V0−V0) = E`。
- `ΔUI = (3/2)nR(2T0−T0) = 3E/2`。
- `QI = ΔUI + WI = 5E/2`。

### 操作 II: B → C（定積冷却）

- `WII = 0`。
- `ΔUII = (3/2)nR(T0−2T0) = −3E/2`。
- `QII = −3E/2`。放出熱量の大きさを問う場合は `3E/2` と書き分ける。

### 操作 III: C → D（断熱圧縮）

`pV^(5/3) = 一定` と状態方程式から `TV^(2/3) = 一定`。よって `TD = TC(VC/VD)^(2/3) = 2^(2/3)T0`。

断熱なので `QIII = 0`。気体が**される**仕事は `Won,III = ΔUIII = (3/2)E[2^(2/3)−1] > 0`。気体が**する**仕事で答える場合は、この負の値になる。

### 本文で保つべき条件

- 固定解除前、外力を `F = pCS = p0S/2` に調整する。固定したまま冷却し外力を `p0S` に保った場合、そのまま解除すると急に圧縮が始まり準静的という条件と整合しないため、設計案にある調整の一文を省かない。
- 調整後、圧縮の進行に合わせて外力をゆっくり増やすと明示できる。初期の `F = p0S/2` を圧縮終了まで一定にする設定ではない。
- 最終状態Dは初期状態Aと体積が同じでも温度と圧力が異なる。この第2問の操作列を「1周のサイクル」とは呼ばない。
- 「熱窓」を「開ける」ときに気体が漏れる窓と誤読されないよう、「気体を漏らさず熱だけを出入りさせる部分」などの説明があるとよい。

断熱変化の公式を提示しているため、断熱公式の導出や積分を要求せず、高校物理の基本演習として解ける。

## 第3問: 状態方程式と内部エネルギー

`n = 0.50 mol`, `R = 8.0 J/(mol·K)`, `p = 1.0×10^5 Pa`, `V = 1.2×10^−2 m³`。

- `pV = 1.2×10^3 J`, `nR = 4.0 J/K`。
- `T = pV/(nR) = 3.0×10^2 K`。
- `U = (3/2)pV = 1.8×10^3 J`。
- 定積で `p′ = 1.5×10^5 Pa` になると `T′ = (p′/p)T = 4.5×10^2 K`。
- `ΔU = (3/2)nR(T′−T) = 9.0×10^2 J`。

単位、値、2桁の有効数字に矛盾はない。温度は絶対温度で扱う。

## 第4問: 熱力学第一法則と符号

| 場合 | Q | W（気体がした仕事） | ΔU | 温度 |
| --- | ---: | ---: | ---: | --- |
| a: 吸熱500 J、気体が200 Jの仕事 | +500 J | +200 J | +300 J | 上昇 |
| b: 定積冷却、Q = −240 J | −240 J | 0 | −240 J | 低下 |
| c: 断熱圧縮、気体が160 Jの仕事をされる | 0 | −160 J | +160 J | 上昇 |

一定量の理想気体では内部エネルギーと絶対温度が対応するため、温度の増減も一意に決まる。aは仕事が正でも内部エネルギーが増える例、bは定積、cは断熱と仕事の符号の復習になる。
