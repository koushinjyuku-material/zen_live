## 判定と共通条件

4題とも物理的に成立し、必要な条件から答えが定まる。第1問の「B → C は全区間で吸熱」は独立に検算して真と確認した。

仕事の符号は `W = 気体が外部にした仕事`、第一法則は `Q = ΔU + W` とする。第1〜3問は一定量の単原子分子理想気体で `U = (3/2)nRT`。第4問は下部開口から空気が出入りするため、全問共通で「一定量」とは指定しない。空気は理想気体として扱えばよく、単原子という指定は第4問には不要。

## 第1問: 負の傾きの辺を持つ三角形サイクル

`A(V0,p0) → B(V0,2p0) → C(3V0,p0) → A`。`E = p0V0 = nRT0` と置く。

- 状態方程式より `TA = T0`, `TB = 2T0`, `TC = 3T0`。
- `A → B` は定積なので `WAB = 0`。
- `B → C` は直線なので、仕事は台形の面積 `WBC = (2p0+p0)(3V0−V0)/2 = 3E`。
- `C → A` は定圧圧縮なので `WCA = p0(V0−3V0) = −2E`。

| 過程 | 気体がした仕事 W | 内部エネルギー変化 ΔU | 吸収熱量 Q |
| --- | ---: | ---: | ---: |
| A → B | 0 | 3E/2 | 3E/2 |
| B → C | 3E | 3E/2 | 9E/2 |
| C → A | −2E | −3E | −5E |
| 1周の合計 | E | 0 | E |

時計回りであり、三角形の面積 `(1/2)(2V0)p0 = E` と正味仕事が一致する。吸熱区間が `A → B` と `B → C` なので、`Qin = 3E/2 + 9E/2 = 6E`、熱効率は `η = E/(6E) = 1/6 ≒ 16.7%`。

### B → C 全区間吸熱の独立検証

問題にはこの条件を提示してよい。以下の微小変化による検算はレビュー用であり、基本問題の生徒解答に要求する必要はない。

`x = V/V0` と置くと、直線BC上で

```text
p = (p0/2)(5 − x),  1 ≦ x ≦ 3,
dp/dV = −p0/(2V0).
```

第一法則と `U = (3/2)pV` から

```text
δQ = dU + p dV
   = [(5/2)p + (3/2)V(dp/dV)]dV
   = p0(25/4 − 2x)dV.
```

BCでは `dV > 0`。係数は `x = 3` で最小の `p0/4 > 0` となるため、全区間で吸熱する。積分しても `QBC = E ∫[1→3](25/4 − 2x)dx = 9E/2` と一致する。

**注意:** `T/T0 = x(5−x)/2` は `x = 5/2` で最大となり、BCの終盤で温度は低下する。「温度が上がり続けるためBC全区間で吸熱」という説明は誤り。温度が下がる部分でも、膨張の仕事が内部エネルギー減少の大きさを上回るため、吸熱になる。

## 第2問: 鉛直ピストンの定圧・定積・断熱操作

断面積 `S`、ピストン質量 `M`、大気圧 `pa`。初期状態で追加外力なし、摩擦なし、力のつり合いから

```text
p0S = paS + Mg,
p0 = pa + Mg/S.
```

`E = p0V0 = nRT0` と置く。

| 状態 | 圧力 | 体積 | 温度 |
| --- | --- | --- | --- |
| A | p0 | V0 | T0 |
| B | p0 | 2V0 | 2T0 |
| C | 2p0 | 2V0 | 4T0 |
| D | 4・2^(2/3)p0 | V0 | 4・2^(2/3)T0 |

### 操作 I: 追加外力なしの準静的加熱膨張

大気圧とピストンの重さが一定なので `p = pa + Mg/S = p0` の定圧変化。

- `WI = p0(2V0−V0) = E`。
- `ΔUI = (3/2)nR(2T0−T0) = 3E/2`。
- `QI = ΔUI + WI = 5E/2`。

### 操作 II: ピストンを固定して追加加熱

- 定積変化より `pC/pB = TC/TB = 2`、したがって `pC = 2p0`。
- `WII = 0`。
- `ΔUII = (3/2)nR(4T0−2T0) = 3E`。
- `QII = 3E`。

### 操作 III: 断熱圧縮

`pV^(5/3) = 一定` と状態方程式より `TV^(2/3) = 一定`。したがって

```text
TD = TC(VC/VD)^(2/3)
   = 4・2^(2/3)T0
   = 2^(8/3)T0.
```

断熱なので `QIII = 0`。気体がされる仕事は

```text
Won,III = ΔUIII
        = (3/2)nR(TD − TC)
        = 6E[2^(2/3) − 1] > 0.
```

### 準静的操作の成立と表記の注意

- 追加の下向き外力を `F` とすると、動く際のつり合いは `pS = paS + Mg + F`、すなわち `F = S(p−p0)`。
- Cで固定を解除する前は `F = p0S` に調整する。加熱後そのまま解除すると上向きに動き始めるため、調整するという設計案の一文を保つ。
- 圧縮中は `p` とともに `F` を徐々に増やすことで準静的操作が成立する。
- 上で求めた「気体がされる仕事」は周囲が気体にする仕事の合計。追加外力 `F` だけの仕事ではない。もし設問を「追加外力Fがした仕事」に変更すると、答えは `WF = Won,III − E` に変わるので、混同しない。
- 熱窓は気体を漏らさず熱のみをやり取りする部分とし、閉じれば断熱になる。容器とピストン自身の熱容量を無視する。
- DはAと体積が等しいだけで圧力・温度が異なり、操作I〜IIIは閉じたサイクルではない。

## 第3問: 状態方程式と内部エネルギー

`n = 0.50 mol`, `R = 8.0 J/(mol·K)`, `p = 1.0×10^5 Pa`, `V = 1.2×10^−2 m³`。

- `pV = 1.2×10^3 J`, `nR = 4.0 J/K`。
- `T = pV/(nR) = 3.0×10^2 K`。
- `U = (3/2)pV = 1.8×10^3 J`。
- 定積で `p′ = 1.5×10^5 Pa` になると `T′ = (p′/p)T = 4.5×10^2 K`。
- `ΔU = (3/2)nR(T′−T) = 9.0×10^2 J`。

単位・値・2桁の有効数字に矛盾はない。

## 第4問: 熱気球の密度と浮力

外気密度 `ρ0 = 1.2 kg/m³`、外気温度 `T0 = 300 K`、容積 `V = 1000 m³`、内部空気を除く気球全体の質量 `M = 300 kg`、`g = 10 m/s²`。

下部開口から空気が出入りするので、加熱前後で内部空気の質量は一定ではない。内外が同じ種類の理想気体で、密度計算では同じ圧力として扱えるため、状態方程式から

```text
ρT = ρ0T0,
ρ = ρ0T0/T = (360/T) kg/m³.
```

### 内部温度400 Kのとき

- 内部密度: `ρ = 1.2×300/400 = 0.90 kg/m³`。
- 内部空気の質量: `m = ρV = 900 kg`。
- 浮力: `B = ρ0Vg = 1.2×1000×10 = 1.2×10^4 N`。
- 全体の重力: `(M+m)g = (300+900)×10 = 1.2×10^4 N`。
- 上向き合力: `Fnet = B−(M+m)g = 0 N`。

400 Kでは中立であり、静止状態から上向きに加速しない。「400 Kで浮き上がる」とは説明しない。

### 浮き上がる温度条件

```text
ρ0Vg > (M + ρ0T0V/T)g,
1.2×1000 > 300 + 1.2×300×1000/T,
T > 400 K.
```

`T = 400 K` はつり合いの境界であり、不等号に等号を含めない。気球の運動開始は上向き合力が正であることに対応する。

### 基本問題としての注意

- 「浮力」は外気が押しのけられる体積に対応する `ρ0Vg` とし、内部空気の重力を別に引く。`(ρ0−ρ)Vg` は内部空気の重力を差し引いた後の上向きの力であり、ここでは浮力そのものとは区別する。
- 支持力・推力・空気抵抗は考えず、浮力と重力の大小を比較する理想モデルとして出題できる。
- 「体積一定だから内部空気の物質量も一定」とはしない。下部開口の説明は残す。
- 熱量や内部エネルギーは問わないため、空気の比熱や単原子分子モデルを持ち込む必要はない。
