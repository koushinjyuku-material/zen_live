## 初期運用

以下は、依頼を継続して実行するために今回整えた運用であり、変更の指示があれば更新する。

- 日本語で作業・記録し、日本時間の日付で日次記録を作成する。
- 継続指示は `AGENTS.md`、確定条件は本ファイル、現在地は `進行状況.md` に保存する。
- 会話と作業結果は `records/`、教材は `materials/` に保存し、各作業で GitHub に同期する。
- 原文、要約、確定した判断、未確定の案を区別して記録する。

## 今回の教材指定（2026-09-09）

- 教科・範囲: 高校物理の熱力学。
- 第1問: セミナー物理の基本問題程度の、三角形のサイクル。
- 第2問: 定圧・定積・断熱変化を組み合わせたピストン問題。「て低圧変化」は文脈から定圧変化として扱った。
- 第3・4問: 基本を振り返る問題。
- 形式: PowerPoint の16:9スライドへ貼り付けるための、LaTeX製PDF。問題と解答は別ファイル。
- 今回の設計: 問題5ページ・解答6ページ。白背景、文字と図をベクトルで作成。ピストン問題は設定と設問を2ページに分ける。
- 対象学年の詳細・授業時間は未指定。今回は基本〜標準の計算問題として構成した。
