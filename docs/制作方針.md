# 制作方針

更新日: 2026-09-09（日本時間）

## 利用者が指定した方針

- このチャットを Zenstudy の教材作成専用として使う。
- 制作に関する記録を、この教材制作プロジェクトと GitHub の `zen_live` に残す。
- 同じ指示を毎回繰り返さなくて済むよう、継続する指示や決定を記録して引き継ぐ。
- 保存先の「Zenstudy」はこの教材制作プロジェクトを意味する。

根拠: [2026-09-09 の依頼・確認](../records/2026-09-09.md)

## 保存先

- ローカル: このリポジトリーのルート以下。
- GitHub: [koushinjyuku-material/zen_live](https://github.com/koushinjyuku-material/zen_live)
- ZEN Study のサービス内への投稿・登録: 対象外。

## 初期運用

以下は、依頼を継続して実行するために今回整えた運用であり、変更の指示があれば更新する。

- 日本語で作業・記録し、日本時間の日付で日次記録を作成する。
- 継続指示は `AGENTS.md`、確定条件は本ファイル、現在地は `進行状況.md` に保存する。
- 会話と作業結果は `records/`、教材は `materials/` に保存し、各作業で GitHub に同期する。
- 原文、要約、確定した判断、未確定の案を区別して記録する。

## 教材ごとに今後決めること

教科・対象学年・授業時間・教材形式・デザイン・難易度・既存テンプレートは、まだ指定されていない。最初の教材制作依頼に合わせて必要な条件を確認し、共通して使う条件はここに追記する。
